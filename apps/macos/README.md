# Sahne for macOS

Sahne 0.5 renders versioned JSON motion-graphics plans to MP4 on Apple silicon. Paste a plan or open `example-plan.json` in the app. The layout uses centered content and a slow zoom across the full composition.

## Build

On macOS with Apple Command Line Tools installed, run `bash build.sh`. The resulting application and ZIP are written to `dist/`. The app is ad hoc signed.

`Resources.zip` contains the application icon, fonts, visual references, and source notices.
